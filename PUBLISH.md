# Publishing ContriboPay to the Google Play Store

Follow these simple steps to prepare and publish your application as a native Android app on the Google Play Store.

## Step 1: Prepare for Android
Since this is a web-based application (PWA), the best way to publish to the Play Store is by using **Trusted Web Activity (TWA)** or a tool like **Bubblewrap** or **Capacitor**.

### Option A: Using Bubblewrap (Recommended for Web Apps)
Bubblewrap is a command-line tool that helps you generate an Android project from your web application.

1. **Install Bubblewrap CLI**:
   ```bash
   npm install -g @bubblewrap/cli
   ```
2. **Initialize your project**:
   ```bash
   bubblewrap init --manifest=https://your-deployed-url.com/manifest.json
   ```
   *Note: Replace `https://your-deployed-url.com` with your actual live URL.*
3. **Build the APK/AAB**:
   ```bash
   bubblewrap build
   ```

## Step 2: Set up a Google Play Developer Account
1. Go to the [Google Play Console](https://play.google.com/console/signup).
2. Sign up and pay the one-time registration fee ($25).
3. Complete your developer profile details.

## Step 3: Create a New App on Play Console
1. Click **Create app**.
2. Select **App** (not Game) and **Free**.
3. Complete the **Initial Setup Tasks**:
   - Set up your Privacy Policy.
   - Declare App Access permissions.
   - Complete Content Ratings.
   - Set up target audience (18+ recommended for financial apps).

## Step 4: Upload your Android App Bundle (.aab)
1. In the Play Console, navigate to **Production** -> **Releases**.
2. Click **Create new release**.
3. Upload the `.aab` file generated by Bubblewrap in Step 1.
4. Add release notes (e.g., "Initial release of ContriboPay Financial Dashboard").

## Step 5: Digital Asset Links (Critical for TWA)
To remove the URL bar from your app and make it look truly native:
1. Google Play will provide you with a **SHA-256 fingerprint** for your app.
2. Create a file named `assetlinks.json` inside a `.well-known` folder on your website.
3. It should look like this:
   ```json
   [{
     "relation": ["delegate_permission/common.handle_all_urls"],
     "target": {
       "namespace": "android_app",
       "package_name": "com.yourname.contribopay",
       "sha256_cert_fingerprints": ["YOUR_SHA256_FINGERPRINT"]
     }
   }]
   ```

## Step 6: Submit for Review
1. Review your release and click **Start rollout to Production**.
2. Google will review your app (typically takes 1-7 days).

---

### Tips for Success:
- **Visuals**: Use the high-resolution logos included in your project for screenshots.
- **Privacy**: Ensure you have a clear Privacy Policy as this handles financial data.
- **Test First**: Use the "Internal Testing" track on Play Console before going live.
